一、目标（一句话）

在现有 Admin CMS（T4.6 标准题库、T4.7 AVG 脚本）上增加 JSON / CSV 单文件 一键导入导出：不使用 zip；列表页支持单条导出、导出全部、导入；冲突时 UI 三选一（覆盖 / 新建 / 取消）；默认草稿，可勾选导入后立即发布。

二、已确认需求 brainstorming

项决策
AVG 范围仅 AvgScript，不含精灵文案
格式标准 JSON+CSV；AVG 仅 JSON
批量载体单文件（questionnaires[] / CSV 多行）
ID 冲突覆盖 / 新建 / 取消（整批统一）
发布默认草稿；可选「导入后立即发布」
CSV每行一题，options_json 嵌入选项数组

六、API 一览

标准题库

GET /admin/questionnaires/:id/export?format=json|csv
GET /admin/questionnaires/export-all?format=json|csv
POST /admin/questionnaires/import multipart: file + format, dry_run, on_conflict, publish_after

AVG 脚本

GET /admin/avg-scripts/:id/export
GET /admin/avg-scripts/export-all
POST /admin/avg-scripts/import（仅 JSON）

路由注意：export-all 须注册在 :id 之前，避免被当作 id。
