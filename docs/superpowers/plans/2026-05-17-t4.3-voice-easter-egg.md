# T4.3 语音彩蛋 Implementation Plan

> **审核入口（HTML + 线框 Demo）**：请用浏览器打开  
> [`2026-05-17-t4.3-voice-easter-egg.html`](./2026-05-17-t4.3-voice-easter-egg.html)  
> 内含验收勾选、语音页线框、落地/音频/交互方案对比。

> **For agentic workers:** 用户批准 HTML 计划后，使用 superpowers:executing-plans 或 subagent-driven-development 按 Task 实施。实施前须 TDD。**禁止**在用户批准前修改 `apps/` 业务源码。

**Goal:** 交付海报二维码语音彩蛋 H5：扫码进入 `/voice/{MBTI}`，用 Web Audio API 播放该类型预录制 MP3；兼容已发出的 `/?from=poster&ref=` 链接；更新 T4.2 海报 QR URL。

**Architecture:** 纯函数校验 type 与 URL → `VoiceWebAudioEngine` 封装 fetch/decode/play → `VoicePlayer` 客户端 UI → `app/voice/[type]` 页面；首页 `PosterQueryRedirect` 处理旧 Q-A；静态资源放 `public/audio/voice/`。

**Tech Stack:** Next.js 14 App Router、Web Audio API、Vitest（mock AudioContext）、可选 Playwright。

**Spec:** [2026-05-17-t4.3-voice-easter-egg-design.md](../specs/2026-05-17-t4.3-voice-easter-egg-design.md)
