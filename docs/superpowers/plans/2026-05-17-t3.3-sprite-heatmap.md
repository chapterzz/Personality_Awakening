## 待你选型（详见 HTML 审核页）

### 图例（四选一）

| ID      | 名称           | 说明                        |
| ------- | -------------- | --------------------------- |
| **L-A** | 渐变条（推荐） | 少 — 渐变条 — 多            |
| **L-B** | 双色分行       | 曦光 / 月影各一行 mini 渐变 |
| **L-C** | 阶梯色块       | 0 / 低 / 中 / 高 四档       |
| **L-D** | 图标 + 文字    | 最简，仅标两只精灵色        |

### 登录列高亮（六选一，chart-3 紫色）

| ID      | 名称       | 说明                      |
| ------- | ---------- | ------------------------- |
| **H-A** | 外环 ring  | 整列 2px 描边（默认推荐） |
| **H-B** | 列顶色带   | 列顶 3px 边框             |
| **H-C** | 列背景淡染 | 22% 紫色底                |
| **H-D** | 外发光     | glow 光晕                 |
| **H-E** | 描边+发光  | 深色模式更醒目            |
| **H-F** | 仅表头     | 表头加粗+下划线，最克制   |

### 单元格配色（已固定）

- 曦光行 `--chart-1`，月影行 `--chart-2`
- `color-mix` 按人数映射深浅（0 人约 8%，满格约 100%）
