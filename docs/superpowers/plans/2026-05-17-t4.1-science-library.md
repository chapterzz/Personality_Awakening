# T4.1 科普图书馆 Implementation Plan

> **审核入口（HTML + 线框 Demo）**：请用浏览器打开  
> [`2026-05-17-t4.1-science-library.html`](./2026-05-17-t4.1-science-library.html)  
> 内含验收勾选、列表/详情静态线框、分类 Tab 与 Markdown 排版方案对比。

> **For agentic workers:** 用户批准 HTML 计划后，使用 superpowers:executing-plans 或 subagent-driven-development 按 Task 实施。实施前须 TDD。**禁止**在用户批准前修改 `apps/` 业务源码。

**Goal:** 交付学生端科普图书馆：已发布文章列表（分类 Tab + 标签筛选）、Slug 详情页（Markdown 阅读）、公开 Nest API 与 Seed 数据，深色模式可读。

**Architecture:** 扩展 `LibraryArticle` 表 → `LibraryModule` 公开只读 API → `library-api.ts` 客户端拉取 → `/library` 与 `/library/[slug]` 页面及组件；Seed 脚本独立命令，契约与 T4.8 CMS 共用表结构。

**Tech Stack:** NestJS 10、Prisma、Next.js 14 App Router、Tailwind/Shadcn、`react-markdown` + `remark-gfm`、Vitest、Jest/supertest。

**Spec:** [2026-05-17-t4.1-science-library-design.md](../specs/2026-05-17-t4.1-science-library-design.md)

// apps/api/src/library/library.service.spec.ts
import { LibraryService } from './library.service';

describe('LibraryService', () => {
  const service = new LibraryService({} as never);

  describe('buildListWhere', () => {
    it('默认仅已发布', () => {
      expect(service.buildListWhere({})).toEqual({
        isPublished: true,
        publishedAt: { not: null },
      });
    });

    it('category 与 tag 组合为 AND', () => {
      expect(service.buildListWhere({ category: 'theory', tag: 'MBTI' })).toMatchObject({
        isPublished: true,
        category: 'theory',
        tags: { has: 'MBTI' },
      });
    });
  });

  describe('collectAvailableTags', () => {
    it('去重并排序标签', () => {
      const tags = service.collectAvailableTags([{ tags: ['B', 'A'] }, { tags: ['A', 'C'] }]);
      expect(tags).toEqual(['A', 'B', 'C']);
    });
  });
});

## 人工验收清单（实施后）

1. `pnpm db:seed:library` 后 `/library` 显示 ≥6 篇文章。
2. 切换分类 Tab，列表变化；点标签 Chip，`?tag=` 生效。
3. 进入详情，Markdown 标题/列表/引用渲染正常。
4. 深色模式下正文与背景对比足够。
5. 未发布文章（Seed 中可留 1 条 `isPublished: false`）不出现在列表且详情 404。
6. `pnpm test:gate` 通过。
