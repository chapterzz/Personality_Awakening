V1 — 内容类型范围

V1-A 仅文章 MVP（推荐）
不迁移 Schema；对齐 T4.1 与任务书验收「增删改文章」；PRD 视频字面留二期

S1 — slug 策略

S1-A 手填 + 唯一校验（推荐）
新建时从标题建议 slug，运营可改；服务端 regex + 查重
S1-B 完全自动生成
标题变更时自动更新 slug（易破坏已发布 URL）

D1 — 删除策略

D1-A 已发布须先下架再删（推荐）
isPublished=true 时 DELETE → 409；草稿可硬删
D1-B 软删 isDeleted
需 Schema 迁移；Admin 列表过滤逻辑更复杂
