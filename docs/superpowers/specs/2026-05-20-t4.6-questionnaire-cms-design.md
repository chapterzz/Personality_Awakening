# T4.6 题库 CMS — 设计规格

**日期**: 2026-05-20  
**范围**: Phase 4 — 后台维护标准模式题库（问卷 / 题目 / 选项 / 维度计分映射）；发布/下架；与 T2.7 自适应题组字段对齐；学生端继续消费已有 `GET /questionnaire/:id`。

**依赖**: T1.2 `StandardQuestionnaire` 表骨架、T1.5 JWT（含 `role`）、T2.4 计分服务（信号模型）、T2.7 自适应题序与公开问卷 API  
**跳过任务影响**: **T4.5 未做** → T4.6 内嵌「最小 Admin 切片」；**T4.4 未做** → 管理端仅保证可用布局，不做全站响应式打磨  
**并行**: T4.7 AVG CMS、T4.8 图书馆 CMS 可后续复用同一 Admin 守卫与 `/admin` 壳层

---

## 1. 背景与目标

### 任务书（T4.6）

后台维护**标准模式**题目、选项、维度/分值映射；支持与 **T2.7** 题组/规则引用；草稿/发布或版本号（**MVP 至少「禁用/启用」**）。

### 验收标准（PPA）

| 项        | 要求                                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| 后台 CRUD | 运营可增删改问卷、题目、选项及计分元数据                                                                              |
| 发布      | `isPublished` 控制学生端可见；发布后 `GET /questionnaire/:id` 返回最新有效题库                                        |
| T2.7 对齐 | `groupTag` / `dimension` / `groupSortOrder` / 选项 `dimension`+`side`+`weight` 与现有 `QuestionnaireService` 规则一致 |
| 计分一致  | 学生端 `buildStandardSignals` 与后端 `POST /scoring/mbti` 使用的信号与 CMS 配置一致                                   |
| 安全      | 非 `ADMIN` 无法调用管理 API（T4.5 缺口由本任务最小补齐）                                                              |

### 现状勘察（2026-05-20）

| 层级                                               | 状态                                                                                                                          |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `prisma/schema.prisma`                             | 已有 `StandardQuestionnaire` / `StandardQuestion` / `StandardQuestionOption`；`isPublished` + `publishedAt` 满足 MVP 发布     |
| `apps/api`                                         | `QuestionnaireModule`：公开 `GET /questionnaire/:id`（仅已发布）、`POST .../sequence`；**无** Admin 路由、**无** `RolesGuard` |
| `apps/web`                                         | 标准测评页硬编码 `adaptive-demo-v1`，经 `questionnaire-api` 拉取；**无** `/admin`                                             |
| `prisma/seed.ts`                                   | 仅 `adaptive-demo-v1` 演示题库                                                                                                |
| `apps/web/src/data/standard-demo-questionnaire.ts` | 遗留 `demo-standard-v1` 本地配置，主路径已走 API                                                                              |
| Admin 目录                                         | **不存在**（T4.5 未实施）                                                                                                     |

**结论**: T4.6 = **最小 Admin 身份与守卫** + **Nest Admin 题库 API** + **Next.js `/admin` 管理 UI** + **校验器单测** + **集成/E2E 发布流验证**。

## 5. 架构

### 5.1 API 分层

```
/admin/questionnaires          GET  列表（含未发布）
/admin/questionnaires          POST 创建问卷
/admin/questionnaires/:id      GET  详情（含题目+选项）
/admin/questionnaires/:id      PATCH 元数据（title 等）
/admin/questionnaires/:id/publish    POST 发布
/admin/questionnaires/:id/unpublish  POST 下架
/admin/questionnaires/:id/questions      POST 新增题目
/admin/questionnaires/:id/questions/:qid PATCH/DELETE
/admin/questions/:qid/options              POST
/admin/options/:oid                      PATCH/DELETE
```

公开端点 **不变**：`GET /questionnaire/:id` 仍 `isPublished: true`。

### 5.2 共享校验（`questionnaire-validation.ts`）

- `dimension`: `EI | SN | TF | JP` 或 null（非自适应题可空）
- `groupTag`: `screening` 或 `{ei,sn,tf,jp}_followup` 等约定值（与 seed 一致）
- 选项：`side` ∈ 对应维度两侧；`weight` ∈ 1..3
- 发布前校验：至少 1 道 `screening` 题；每题 ≥2 选项；计分题选项须完整三元组

### 5.3 前端管理页（线框见 HTML 计划）

| 路由                         | 职责                          |
| ---------------------------- | ----------------------------- |
| `/admin/login`               | 昵称+密码，仅允许 ADMIN       |
| `/admin`                     | 重定向到问卷列表              |
| `/admin/questionnaires`      | 问卷列表、新建、发布状态      |
| `/admin/questionnaires/[id]` | 题目列表、编辑选项、发布/下架 |

### 5.4 与计分 / T2.7 的关系

- **T2.7**：`generateOrderedQuestionIds` 读 DB 中 `groupTag`/`dimension`；CMS 改字段后无需改代码即可影响题序（规则阈值仍在 service）。
- **计分**：客户端从 `GET /questionnaire/:id` 拉选项元数据 → `buildStandardSignals` → `/scoring/mbti`；CMS 改 `side`/`weight` 即改变结果，**发布前须在后台展示计分预览或警告**（MVP：文案提示 + 校验必填）。

## 6. 数据模型

**MVP 不新增表字段**。可选二期：`StandardQuestion.isEnabled`、`version` 备注。

Seed 扩展（T4.6 交付）：

- `pnpm db:seed:admin` 或合并进 `seed.ts`：用户 `nickname: ppa-admin`，`role: ADMIN`，密码来自 `.env` `SEED_ADMIN_PASSWORD`（默认仅开发）。
