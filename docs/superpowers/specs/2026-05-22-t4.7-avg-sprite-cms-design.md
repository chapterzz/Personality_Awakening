**日期**: 2026-05-22  
**范围**: Phase 4 — 后台维护 AVG 剧情配置（节点、分支、选项、背景资源 key）与精灵互动文案（犹豫提示、互斥吐槽）；学生端 AVG 引擎与 T2.3 精灵 Hook 改从 API 拉取已发布内容。

**依赖**: T1.2 `AvgScript` 表骨架、T1.4/T2.2 AVG 进度与引擎、T2.3 精灵互动、T4.6 Admin 守卫与 `/admin` 壳层  
**并行**: T4.8 图书馆 CMS 可继续复用同一 Admin 布局与 `RolesGuard`

## 1. 背景与目标

### 任务书（T4.7）

后台维护 AVG **剧情配置**（JSON 或结构化表单：节点、分支、选项、资源 key）；**精灵提示/吐槽等文案**可编辑；与学生端 AVG 引擎读取格式一致。

### 验收标准（PPA）

| 项       | 要求                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| AVG CRUD | ADMIN 可维护脚本元数据、`nodesJson`（含 nodes / backgrounds / start_node_id）                            |
| 精灵文案 | ADMIN 可编辑犹豫提示（多条）与四维互斥文案（EI/SN/TF/JP 各多条）                                         |
| 发布     | `isPublished` 控制学生端可见；改文案/节点后学生端可加载新版本                                            |
| 格式一致 | 公开 API 响应与 `AvgScriptConfig`（`apps/web/src/data/avg-demo-script.ts`）及 `sprite-lines.ts` 语义一致 |
| 安全     | 非 `ADMIN` 无法调用 `/admin/avg-*`、`/admin/sprite-*`                                                    |
| 进度兼容 | 进行中 AVG 会话 `script_id` 不匹配时仍走现有 `script_mismatch` 分支                                      |

### 现状勘察（2026-05-22）

| 层级                                 | 状态                                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------------------- |

| `prisma/seed.ts`                     | **未** Seed `AvgScript`；AVG 仍靠前端常量                                                      |

## 5. 架构

### 5.1 API 分层

**公开（学生端）**

```
GET /avg-script/:id          → AvgScriptConfig 形状（仅 isPublished=true）
GET /sprite-prompts          → { hesitationLines, mutexLines }（仅已发布）
```

**Admin（需 ADMIN JWT）**

```
GET    /admin/avg-scripts              列表
POST   /admin/avg-scripts              创建（MVP 可限制仅允许 1 条演示）
GET    /admin/avg-scripts/:id            详情（含 nodesJson）
PATCH  /admin/avg-scripts/:id          元数据 title
PUT    /admin/avg-scripts/:id/nodes    更新 nodesJson（校验后写入）
POST   /admin/avg-scripts/:id/publish
POST   /admin/avg-scripts/:id/unpublish

GET    /admin/sprite-prompts           当前配置（含未发布草稿）
PUT    /admin/sprite-prompts           更新 hesitationLines + mutexLines
POST   /admin/sprite-prompts/publish
POST   /admin/sprite-prompts/unpublish
```

### 5.2 共享校验（`avg-script-validation.ts`）

对齐 `apps/web/src/data/avg-demo-script.ts` 类型约定：

- `start_node_id` 非空且存在于 `nodes`
- 每个 node：`kind` ∈ `dialogue | choice | end`
- `dialogue` 须有 `next_id` 指向有效节点
- `choice` 须有 ≥2 `options`，每项 `id`/`label`/`next_id` 合法；计分信号 `dimension`/`side`/`weight` 可选但须三元完整
- `end` 无 `next_id`
- `backgrounds` 每个 key 被引用时存在；值可为 string 或 `{ gradientClassName?, imageUrl?, lottieUrl? }`
- 从 `start_node_id` BFS/DFS 可达性（无孤立死链）；至少 1 个 `end` 节点
- 发布前：可达 `end`；choice 节点选项 id 在脚本内唯一

**精灵文案校验**（`sprite-prompt-validation.ts`）：

- `hesitationLines`: 非空 `string[]`，每项 trim 后长度 1–200
- `mutexLines`: 键必须含 `EI|SN|TF|JP`，每维至少 1 条

### 5.3 前端管理页（线框见 HTML 计划）

| 路由                      | 职责                                                 |
| ------------------------- | ---------------------------------------------------- |
| `/admin/avg-scripts`      | 脚本列表、新建、发布状态                             |
| `/admin/avg-scripts/[id]` | 元数据、JSON 编辑区、校验结果、节点预览表、发布/下架 |
| `/admin/sprite-prompts`   | 犹豫文案列表编辑、四维互斥文案 textarea/列表、发布   |

### 5.4 学生端改造

| 文件                                                      | 变更                                                  |
| --------------------------------------------------------- | ----------------------------------------------------- |
| `apps/web/src/lib/avg-script-api.ts`                      | `fetchPublishedAvgScript(id)`                         |
| `apps/web/src/lib/sprite-prompt-api.ts`                   | `fetchPublishedSpritePrompts()`                       |
| `apps/web/src/app/test/avg/avg-test-client.tsx`           | mount 时拉脚本；loading/error 态                      |
| `apps/web/src/app/test/standard/standard-test-client.tsx` | 精灵 Hook 注入 API 文案（或共享 Provider）            |
| `apps/web/src/data/avg-demo-script.ts`                    | 保留 **类型导出** + 测试/fixture 用 `DEMO_AVG_SCRIPT` |
| `apps/web/src/data/sprite-lines.ts`                       | 保留 fallback 常量供单测；运行时优先 API              |

**script_mismatch**: `useAvgTest` 已有 `progressData.avg.script_id !== config.script_id` 检测；CMS 改 id 或换脚本时行为不变。

### 5.5 与 T2.2 / T2.3 / T2.4 的关系

- **T2.2 引擎**：仍消费 `AvgScriptConfig`；仅数据源从常量 → API
- **T2.3 精灵**：`useSpriteInteraction` 接口不变；调用方传入 API 拉取的 `getHesitationLine` / `getMutexLine` 工厂
- **T2.4 计分**：AVG 选项 `dimension/side/weight` 仍由 `buildAvgSignals` 读取；CMS 改 option 元数据即改计分信号

## 6. 数据模型

### 6.1 已有 `AvgScript`（不改动字段）

```prisma
model AvgScript {
  id          String    @id
  title       String
  nodesJson   Json      @map("nodes_json")
  publishedAt DateTime? @map("published_at")
  isPublished Boolean   @default(false) @map("is_published")
  @@map("avg_scripts")
}
```

`nodesJson` 示例（不含 `script_id`）：

```json
{
  "start_node_id": "intro",
  "backgrounds": { "night": "from-indigo-950 via-slate-900 to-slate-950" },
  "nodes": {
    "intro": { "kind": "dialogue", "background_key": "night", "lines": [], "next_id": "..." }
  }
}
```

公开 API 组装：`{ script_id: id, ...nodesJson }`。

### 6.2 新增 `SpritePromptConfig`（MVP 迁移）

```prisma
model SpritePromptConfig {
  id              String    @id @default("default")
  hesitationLines Json      @map("hesitation_lines")
  mutexLines      Json      @map("mutex_lines")
  publishedAt     DateTime? @map("published_at")
  isPublished     Boolean   @default(false) @map("is_published")

  @@map("sprite_prompt_configs")
}
```

Seed 默认值来自现有 `apps/web/src/data/sprite-lines.ts`。

## 9. 风险

| 风险                       | 缓解                                             |

| 改 node_id 破坏进行中进度  | 发布前警告；运营手册说明                         |

| Admin 布局仍标「题库 CMS」 | T4.7 一并改顶栏为「内容 CMS」                    |
