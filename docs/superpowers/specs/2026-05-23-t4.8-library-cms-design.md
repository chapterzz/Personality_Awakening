## 5. 架构

### 5.1 API 分层

**公开（学生端）— 不变**

```
GET /library/articles       → 已有（仅 isPublished=true）
GET /library/articles/:slug → 已有
```

**Admin（需 ADMIN JWT）— 新增**

```
GET    /admin/library/articles              列表（含未发布，可按 category/isPublished 筛选）
POST   /admin/library/articles              创建草稿
GET    /admin/library/articles/:id          详情（含 body_md）
PATCH  /admin/library/articles/:id          更新元数据 + 正文 + tags
DELETE /admin/library/articles/:id          删除（已发布 → 409 或须先下架）
POST   /admin/library/articles/:id/publish    发布（写 publishedAt）
POST   /admin/library/articles/:id/unpublish  下架（isPublished=false，保留 publishedAt 历史可选）
```

Admin 响应字段使用 **camelCase**（与现有 Admin 问卷 API 一致）；公开 API 保持 **snake_case**（T4.1 契约）。

### 5.2 共享校验（`library-validation.ts`）

- `slug`: `/^[a-z0-9]+(?:-[a-z0-9]+)*$/`，长度 2–80，唯一（创建/更新时查重）
- `title`: trim 后 1–120 字符
- `bodyMd`: trim 后 ≥ 10 字符（发布前）
- `excerpt`: 可选，≤ 300 字符
- `category`: ∈ `LIBRARY_CATEGORIES`
- `tags`: 数组 0–10 项，每项 trim 后 1–32 字符，去重
- 发布前：`validateArticleForPublish(article)` 聚合上述规则

### 5.3 服务层

- **`AdminLibraryCmsService`**: CRUD + publish/unpublish，直接 `prisma.libraryArticle`
- **`LibraryService`**: 保持只读公开查询，**不**混入 Admin 逻辑（边界清晰）
- 可选：Admin 列表复用 `LibraryService.collectAvailableTags` 作为 util 导出

### 5.4 前端管理页（线框见 HTML 计划）

| 路由                           | 职责                                           |
| ------------------------------ | ---------------------------------------------- |
| `/admin/library/articles`      | 文章列表、分类/状态筛选、新建、发布状态        |
| `/admin/library/articles/new`  | 创建表单（标题、slug、分类、标签、摘要、正文） |
| `/admin/library/articles/[id]` | 编辑 + Markdown 预览 + 发布/下架/删除          |

### 5.5 学生端

| 文件                      | 变更（文章 MVP）    |
| ------------------------- | ------------------- |
| `/library/*`              | **无改动**          |
| `lib/library-api.ts`      | **无改动**          |
| E2E `e2e/library.spec.ts` | 可选增 Admin 发布流 |

选用 **V1-B 视频元数据** 时额外：Schema 迁移、`library-types` 扩展、`article-card` 显示视频徽章、详情页外链/iframe MVP。

## 6. 数据模型

### 6.1 已有 `LibraryArticle`（文章 MVP 不改动）

```prisma
model LibraryArticle {
  id          String    @id @default(uuid()) @db.Uuid
  title       String
  slug        String    @unique
  bodyMd      String    @map("body_md")
  excerpt     String?
  category    String    @default("theory")
  tags        String[]  @default([])
  publishedAt DateTime? @map("published_at")
  isPublished Boolean   @default(false) @map("is_published")

  @@index([isPublished, category])
  @@map("library_articles")
}
```

### 6.2 二期可选扩展（V1-B）

| 字段          | 类型      | 说明                                        |
| ------------- | --------- | ------------------------------------------- |
| `contentType` | `String`  | `article` \| `video`，默认 `article`        |
| `videoUrl`    | `String?` | 外链（B 站/优酷等）；`video` 类型发布前必填 |
| `coverUrl`    | `String?` | 列表卡片封面（可选）                        |

## 9. 风险

| 风险                        | 缓解                                           |
| --------------------------- | ---------------------------------------------- |
| Markdown 中恶意链接         | `react-markdown` 默认不渲染 raw HTML；运营规范 |
| slug 变更导致旧链接 404     | Admin 编辑页警告「slug 发布后慎改」            |
| 误删已发布文章              | 已发布删除前 409；或二次确认对话框             |
| PRD「视频」与 T4.1 范围冲突 | MVP 文章优先；视频元数据作为明确选型项 V1-B    |
