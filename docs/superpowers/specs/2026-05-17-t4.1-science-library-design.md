# T4.1 科普图书馆 — 设计规格

**日期**: 2026-05-17  
**范围**: Phase 4 学生端 — 文章列表、详情、标签/分类筛选；数据来自 `LibraryArticle`（Seed 先行，与 T4.8 CMS 契约对齐）

**依赖**: T1.2 `LibraryArticle` 表骨架、T1.6 布局/深色模式、T3.x 看板 API 模式（公开 Nest 端点 + 前端 `fetch`）  
**并行**: T4.2 海报、T4.4 响应式、T4.5 Admin 骨架；**不阻塞** T4.8，但字段与 API 须可被 CMS 复用  
**后续消费**: T4.8 图书馆 CMS 写入同一表与发布字段；T5.2 E2E 可增「浏览图书馆」路径

---

## 1. 背景与目标

### 任务书（T4.1）

开发**科普图书馆**：文章列表、详情页，支持**标签筛选**；内容数据来自 **T4.8 发布后的数据源**（或 Seed，最终与 CMS 对齐）。

### 验收标准（PPA）

| 项         | 要求                                                              |
| ---------- | ----------------------------------------------------------------- |
| 列表与详情 | 可浏览已发布文章；详情展示正文                                    |
| 标签筛选   | 可按标签（及/或分类）过滤列表                                     |
| 阅读体验   | 排版清晰、移动端可读                                              |
| 深色模式   | 与全站 `next-themes` 一致                                         |
| 数据源     | Seed 或 DB 中 `is_published = true`；不实现 Admin 后台（属 T4.8） |

### 产品范围（PRD §1.5 / BRD）

- **包含（MVP）**: 分类维度（基础理论、反标签、名人案例）、文章 Markdown 正文、公开访问。
- **排除（本任务）**: 互动小测与徽章解锁、视频播放/CMS 编辑界面、底部四 Tab 导航（留 T4.4）、复杂全文搜索。

### 现状勘察（2026-05-17）

| 层级                   | 状态                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `prisma/schema.prisma` | 已有 `LibraryArticle`：`title`, `slug`, `bodyMd`, `excerpt`, `publishedAt`, `isPublished`；**无** `category` / `tags` |
| `prisma/seed.ts`       | 仅自适应题库，**无**图书馆 Seed                                                                                       |
| `apps/api`             | **无** `LibraryModule` / 图书馆路由                                                                                   |
| `apps/web`             | **无** `/library` 路由；首页无图书馆入口；无 Markdown 依赖                                                            |
| `PPA_Tech_SPEC.md`     | §5.3 将 T4.x 归为「校验器 + Admin API + 学生端拉取」；无图书馆专节，本 spec 补契约                                    |

**结论**: T4.1 为**从零交付**学生端阅读链路 + 最小 Schema 扩展 + 公开 API + Seed，模式对齐 T3.1 Dashboard。

## 4. 数据模型

### 4.1 Schema 扩展（T4.1 迁移）

在 `LibraryArticle` 上新增：

| 字段       | 类型       | 说明                                                                 |
| ---------- | ---------- | -------------------------------------------------------------------- |
| `category` | `String`   | 枚举值：`theory` \| `anti_label` \| `celebrity`（与 PRD 三分类对应） |
| `tags`     | `String[]` | PostgreSQL 数组，默认 `[]`；示例：`["MBTI","信度"]`                  |

索引建议：`@@index([isPublished, category])`，`slug` 保持 `@unique`。

### 4.2 发布规则

- 学生端仅查询 `is_published = true` 且 `published_at IS NOT NULL`（`published_at` 可为 Seed 写入时间）。
- T4.8 CMS 沿用 `isPublished` / `publishedAt` 上下架，不新增平行状态机。

### 4.3 Seed（`prisma/seed-library.ts`）

- 根脚本：`pnpm db:seed:library`（与 `db:seed:dashboard` 并列）。
- 至少 **6 篇**演示文：每分类 ≥2 篇，覆盖 2–3 个不同 `tags`。
- 正文为简短中文 Markdown（标题、列表、引用块），含「娱乐参考，非医疗诊断」类免责声明一篇。

## 5. API 设计

### 5.1 端点

| 方法 | 路径                      | 认证 | 说明                             |
| ---- | ------------------------- | ---- | -------------------------------- |
| GET  | `/library/articles`       | 无   | 列表；Query：`category?`, `tag?` |
| GET  | `/library/articles/:slug` | 无   | 详情；仅已发布                   |

### 5.2 响应契约（`success/data/message`）

**列表项 `LibraryArticleSummary`:**

```typescript
{
  id: string;
  title: string;
  slug: string;
  excerpt: string | null;
  category: 'theory' | 'anti_label' | 'celebrity';
  tags: string[];
  published_at: string; // ISO
}
```

**详情 `LibraryArticleDetail`:** 在 Summary 基础上增加 `body_md: string`。

**列表 `data`:**

```typescript
{
  articles: LibraryArticleSummary[];
  available_tags: string[]; // 当前筛选条件下仍出现的标签并集，供 Chips 展示
}
```

- `tag` 查询：筛选 `tags` 数组 **包含** 该字符串（PostgreSQL `@>` 或 `has`）。
- `category` 与 `tag` 同时存在时为 **AND**。
- 无匹配：返回 `articles: []`，非 404。

### 5.3 错误

- 未知 `slug` 或未发布：`404`，`message` 友好文案。
- 非法 `category` 查询值：`400`（DTO 校验）。

## 6. 前端设计

### 6.1 路由

| 路径              | 页面                          | 说明                         |
| ----------------- | ----------------------------- | ---------------------------- |
| `/library`        | `app/library/page.tsx`        | 列表 + 分类 Tab + 标签 Chips |
| `/library/[slug]` | `app/library/[slug]/page.tsx` | 详情 + Markdown 正文         |

### 6.2 组件

| 文件                                   | 职责                                                |
| -------------------------------------- | --------------------------------------------------- |
| `components/library/library-hero.tsx`  | 标题区 + 科普说明一句                               |
| `components/library/category-tabs.tsx` | 三分类 +「全部」                                    |
| `components/library/tag-filter.tsx`    | 标签 Chips；同步 URL `?tag=`                        |
| `components/library/article-card.tsx`  | 列表卡片：标题、摘要、分类徽章、标签                |
| `components/library/article-body.tsx`  | Markdown 渲染 + `prose` 深色样式                    |
| `lib/library-api.ts`                   | `fetchLibraryArticles`, `fetchLibraryArticleBySlug` |
| `lib/library-types.ts`                 | 与 API 一致的 TS 类型                               |
| `lib/library-labels.ts`                | 分类中文名、标签展示纯函数（可单测）                |

### 6.3 UI/UX

- 延续 **Claymorphism** 卡片、`font-display` 标题，与首页/看板一致。
- 详情页：最大宽度 `prose` 窄栏（约 `max-w-3xl`），行高舒适；文内 `h2/h3/blockquote/code` 有深色变量。
- 列表空态：「暂无文章，敬请期待」插画文案区。
- 页顶「返回科普馆」链回列表（保留当前 `category`/`tag` query 可选）。

### 6.4 伦理与合规

- 列表 Hero 或详情页脚固定展示：**「内容仅供科普与娱乐参考，不能替代专业心理评估或医疗诊断。」**
