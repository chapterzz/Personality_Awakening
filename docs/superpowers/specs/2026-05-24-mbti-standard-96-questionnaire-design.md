# 标准模式 MBTI 测试题库（96题总库）设计文档

> **设计日期**：2026-05-24  
> **设计者**：AI 心理计量学专家（Claude Code）  
> **目标用户**：初一女生，喜爱阅读、昆虫、火影忍者、博物杂志，读过哈利波特、少年历史课、高尔基三部曲、罪与罚、安娜、西游记  
> **用途**：作为标准模式总题库导入 CMS，后续每次从中随机抽取 48 题（每维度 12 题）组成测试

---

## 1. 背景与目标

### 1.1 为什么需要新题库

现有 `demo-standard-v1` 仅 12 题，体量不足，且语言风格偏通用，未针对目标用户群体做深度适配。本项目需要一套：

1. **符合荣格人格理论**、具备高信效度的题库
2. **语言风格精准匹配**初一女生用户画像（生活化、现代化、融入其兴趣背景）
3. **体量充足**（96题总库），支持后续随机抽取 48 题的测试模式
4. **可直接导入**现有 CMS 的 JSON 格式

### 1.2 核心设计原则

| 原则           | 说明                                                             |
| -------------- | ---------------------------------------------------------------- |
| **理论驱动**   | 每道题必须锚定荣格四维度之一的明确子特质，避免"万能题"           |
| **用户中心**   | 语言风格现代化、生活化，场景贴近初一女生日常，避免心理学教条     |
| **兴趣融入**   | 核心题目用用户熟悉的兴趣元素（昆虫、火影、哈利波特等）做场景包装 |
| **信效度优先** | 区分度高的核心题目 weight=3，情境性边缘题 weight=1，确保测量精度 |

## 2. 理论框架

### 2.1 荣格四维度与子特质组

每个维度按荣格理论的**核心行为表现**划分为 4 个子特质组，每组 6 题：

**EI（外向 Extraversion / 内向 Introversion）**

- 能量恢复方式（Energy Source）：社交充电 vs 独处充电
- 社交参与模式（Social Engagement）：主动发起 vs 被动响应
- 信息处理偏好（Information Processing）：边说边想 vs 想好再说
- 群体中的角色（Group Role）：活跃参与者 vs 安静观察者

**SN（感觉 Sensing / 直觉 Intuition）**

- 注意力焦点（Attention Focus）：关注细节 vs 关注整体
- 信息偏好（Information Preference）：具体实用 vs 抽象概念
- 现实导向（Reality Orientation）：立足当下 vs 展望未来
- 经验方式（Experience Style）：直接体验 vs 联想延伸

**TF（思考 Thinking / 情感 Feeling）**

- 决策依据（Decision Basis）：逻辑规则 vs 人际和谐
- 冲突处理（Conflict Handling）：对错分明 vs 照顾感受
- 评价标准（Evaluation Criteria）：客观标准 vs 主观价值
- 反馈方式（Feedback Style）：直接指出 vs 委婉表达

**JP（判断 Judging / 知觉 Perceiving）**

- 时间组织（Time Organization）：计划先行 vs 随机应变
- 结构偏好（Structure Preference）：明确规则 vs 灵活框架
- 完成方式（Completion Style）：尽快完成 vs 保持开放
- 变化应对（Change Response）：维持稳定 vs 适应变化

### 2.2 Weight 分配策略

每道题的两个选项使用**相同 weight**，weight 反映整道题目的区分度：

| Weight | 含义                                                       | 数量（每维度） | 数量（总计） |
| ------ | ---------------------------------------------------------- | -------------- | ------------ |
| 3      | **核心区分题**：最典型、最清晰地区分维度两端，理论对应度高 | 8题            | 32题         |
| 2      | **一般测量题**：能测量该维度，但可能受轻微情境影响         | 12题           | 48题         |
| 1      | **边缘情境题**：情境性较强，或维度表现可能不太稳定         | 4题            | 16题         |

分配规则（每组6题）：2题×3 + 3题×2 + 1题×1

## 3. 语言风格与兴趣元素

### 3.1 语言风格特征

- **现代化**：使用当下中学生熟悉的表达方式（"回血"、"吐槽"、"破冰"、"社死"等）
- **生活化**：场景来自真实中学生活（课间、小组作业、班级活动、放学路上）
- **去教条化**：避免"你倾向于...""在人际关系中..."等心理学腔调，改用具体场景提问
- **选项对等**：两个选项都是合理的、可接受的选择，没有"正确"答案

### 3.2 兴趣元素融入规则

**可用元素池**：

- 昆虫观察 / 博物杂志（自然科普场景）
- 火影忍者（忍者小队、任务、羁绊、修炼、忍术）
- 哈利波特（霍格沃茨、分院、课程、魁地奇、魔法世界）
- 阅读（哈利波特、罪与罚、安娜·卡列尼娜、西游记、高尔基三部曲、少年历史课）
- 西游记（取经团队、人物性格）

**融入原则**：

1. **核心题目优先**（weight=3 的题目优先使用兴趣元素包装）
2. **场景化包装**：用兴趣相关的场景替代抽象提问（如"如果你是忍者小队成员..."而非"你喜欢团队合作吗"）
3. **自然融入**：不为融入而强行关联，兴趣元素必须与题目测量的子特质有逻辑关联
4. **适度分散**：避免所有题目都来自同一兴趣源，保持多样性

## 5. 题目样例（EI 维度完整24题）

见下方完整题库 JSON 文件。此处以 EI 第1题说明设计思路：

```
q_ei_01 | weight=3 | 能量恢复方式
Prompt: 连续几天的社团活动后，周末你更想怎么"回血"？
A(E): 约朋友出去逛逛，聊天吐槽，人越多越开心
B(I): 一个人待着，看喜欢的书或追番，安安静静充电
```

**设计说明**：

- 锚定子特质：能量恢复方式（EI 最核心的子特质之一）
- weight=3：这是 EI 维度最经典的行为指标，区分度极高
- 语言风格：使用"回血""吐槽""追番"等中学生日常用语
- 场景自然：周末放松是初中生普遍经历的情境

## 6. JSON 格式与导入方式

### 6.1 格式规范

文件符合项目 CMS 导入导出标准（`schema_version: 1`，snake_case 字段）：

```json
{
  "schema_version": 1,
  "id": "standard-96-v1",
  "title": "标准模式MBTI测试题库（96题总库）",
  "questions": [
    {
      "id": "q_ei_01",
      "prompt": "...",
      "sort_order": 1,
      "dimension": "EI",
      "group_tag": null,
      "group_sort_order": null,
      "options": [
        {
          "id": "q_ei_01_A",
          "label": "...",
          "value_key": "A",
          "dimension": "EI",
          "side": "E",
          "weight": 3
        },
        {
          "id": "q_ei_01_B",
          "label": "...",
          "value_key": "B",
          "dimension": "EI",
          "side": "I",
          "weight": 3
        }
      ]
    }
  ]
}
```

### 6.2 关键字段说明

| 字段               | 值                              | 说明                                   |
| ------------------ | ------------------------------- | -------------------------------------- |
| `schema_version`   | 1                               | 与导入导出模块兼容                     |
| `id`               | `standard-96-v1`                | 问卷唯一标识                           |
| `group_tag`        | `null`                          | 标准模式不使用 screening/followup 机制 |
| `group_sort_order` | `null`                          | 同上                                   |
| `dimension`        | `EI`/`SN`/`TF`/`JP`             | 题目所属维度                           |
| `side`             | `E`/`I`/`S`/`N`/`T`/`F`/`J`/`P` | 选项指向的维度端                       |
| `weight`           | 1/2/3                           | 选项权重，两选项相同                   |

### 6.3 导入步骤

1. 登录 Admin 后台 → 题库管理
2. 点击"导入" → 选择 JSON 格式
3. 上传 `standard-96-questionnaire.json`
4. 冲突策略选择"创建新问卷"（如 id 冲突）
5. 导入成功后可在题库列表中看到 `standard-96-v1`

## 7. 后续随机抽取机制（待实现）

本题库作为**总库**使用，实际测试时从每维度随机抽取 12 题组成 48 题测试卷。

**抽取策略建议**：

- 优先保证 weight=3 的核心题目被抽中（如每维度至少抽 4 道 weight=3 的题）
- 或完全随机抽取，让大数定律自然平衡区分度
- 抽取结果缓存至 `TemporarySession.progress_data.standard.ordered_question_ids`
