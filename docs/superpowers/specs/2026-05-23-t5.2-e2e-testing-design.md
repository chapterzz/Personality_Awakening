## 2. 跳过 T5.1 的影响、缺口与降级

| T5.1 原计划               | 对 T5.2 的影响                               | 降级策略                                                                                                                         |
| ------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |

| Admin/CMS 越权、批量导出  | 任务书曾期望 T5.1 覆盖                       | **已有** `admin-questionnaire/avg/library.e2e-spec.ts`（supertest 403）；T5.2 **P1** 可选 1 条 Playwright：`/admin` 未登录重定向 |

| 审计日志                  | 无审计表，无法 E2E 验日志                    | **明确 out of scope**；T5.1 补做时再建                                                                                           |

## 4. 方案对比

| 方案                            | 说明                                                                                          | 优点                                | 缺点                                       | 结论           |
| ------------------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------- | ------------------------------------------ | -------------- |
| **A. 分层 Golden Path（推荐）** | P0：UI 注册+demo 结果→看板；P0：guest 看板 smoke；P0：seed 完成→报告→点看板；既有分段用例保留 | 稳定、快、对齐 §5.3；不重复答 93 题 | 「测试」UI 点击路径靠 AVG 子集用例间接覆盖 | **采用**       |
| B. 单条超长 UI 全流程           | 注册后从第 1 题点完标准卷→报告→看板                                                           | 字面最接近任务书                    | 自适应题量大、超时/flaky、CI 慢            | 不采用         |

| D. Cypress 双栈                 | 任务书提 Playwright/Cypress                                                                   | —                                   | 仓库已定 Playwright                        | 不采用         |

## 5. 推荐架构

### 5.1 用例分层

```
Tier 0 — 既有 smoke（14 tests）          不删，跑通即回归
Tier 1 — 看板 smoke（guest + logged-in）  新增 dashboard*.spec.ts
Tier 2 — Golden Path 注册→看板            新增 golden-path-register-dashboard.spec.ts
Tier 3 — 测评→报告→看板导航               新增 golden-path-test-to-dashboard.spec.ts
Tier 4 — Admin guard（可选 P1）           新增 admin-guard.spec.ts
```

### 5.2 新增 Helpers

**`e2e/helpers/auth-ui.ts`**

- `uniqueNickname(prefix)` → `e2e-user-${randomUUID().slice(0,8)}`
- `registerViaUi(page, { mbtiType, withDemoResult })` → 填表、提交、等待跳转

**`e2e/helpers/dashboard-assertions.ts`**

- `expectDashboardLoaded(page)` → Hero「性格星球 · 全局洞察」
- `expectPersonalComparison(page, mbtiType)` → 「你是 {type} 类型」

### 5.3 数据策略

| 场景                           | 策略                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------ |
| Guest 看板有图表               | **不强制** globalSetup seed；断言 Hero + 「类型分布」标题；`totalUsers` 可为 0 |
| Logged-in 个人对比             | 注册时勾选 **演示测评结果**（默认 INFP），自包含、不依赖 seed                  |
| 测评→报告                      | 继续 **PUT progress seed** + mock `scoring/mbti`（与现有 spec 一致）           |
| 全局 stats 非空断言（可选 P2） | 文档说明本地可先 `pnpm db:seed:dashboard`；CI 不强制                           |

### 5.4 选择器约定

- 优先 `getByRole` / `getByText`（与现有 spec 一致）
- 看板：`heading`「性格星球 · 全局洞察」、`你的位置`、`16 型人格分布`、`趣味数据`
- 导航：Header `看板`（sm+）或首页 CTA `全局洞察看板`

### 5.5 稳定性

- 超时：看板 API 60s（与 AVG 一致）
- `page.route('**/scoring/mbti')` 仅报告相关 spec 保留
- CI：`retries: 2`, `workers: 1`（已配置）
- 不新增 parallel 共享同一 nickname 的用例

## 6. 新增 Spec 概要

### 6.1 `e2e/dashboard-guest.spec.ts`

1. `goto /dashboard`
2. 断言 Hero、「16 型人格分布」、精灵热力图区、「趣味数据」可见
3. 断言 guest 提示「登录后可高亮…」

### 6.2 `e2e/golden-path-register-dashboard.spec.ts`

1. `goto /login?redirect=/dashboard`
2. 切「注册」、填昵称/密码、保持「演示测评结果」勾选、选 INFP
3. 提交 → URL `/dashboard`
4. 断言 `PersonalComparison`「你是 INFP 类型」
5. 断言柱状图区可见（不解析 Recharts SVG 数值）

### 6.3 `e2e/golden-path-test-to-dashboard.spec.ts`

1. Guest seed 标准完成（复用 helper）
2. 进报告页 → 断言 ENTJ
3. 点击 Header「看板」或首页 CTA 到 `/dashboard`
4. 断言看板加载

### 6.4 `e2e/admin-guard.spec.ts`（P1，G2-A 选用时）

1. `goto /admin/questionnaires` 无 token → 重定向 `/admin/login`
2. （可选）STUDENT 账号登录 admin 页 → 错误文案
