# T3.4 趣味数据卡片与个人对比 — 设计规格

**日期**: 2026-05-17  
**范围**: Phase 3 看板前端 — `FunInsightCards`、`PersonalComparison` 验收级完善（T3.1 聚合 API 与初版 UI 已存在）

**依赖**: [2026-05-16-dashboard-design.md](./2026-05-16-dashboard-design.md)、T3.1 `GET /dashboard/stats` / `GET /dashboard/my-comparison`、T3.2 柱图高亮约定、T3.3 热力图样式变量

## 1. 背景与目标

### 任务书（T3.4）

开发趣味数据卡片组（**最常见类型**、**最稀有类型**、**最受欢迎精灵**、**维度平衡度**）；登录用户展示**个人类型与全局对比**。

### 验收标准（PPA）

| 项                 | 要求                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| 卡片数据准确       | 与 `stats.funInsights` 一致；维度条比例与 `dimensionBalance` 一致     |
| 未登录隐藏个人对比 | **不渲染** `PersonalComparison`；页面保留现有游客提示条（去登录）     |
| P1 优先级          | 不扩展 API 字段；后端逻辑以 T3.1 为准，仅在前端发现契约偏差时最小修补 |

### 现状（2026-05-17 勘察）

| 层级                               | 状态                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------- |
| `DashboardService.getStats`        | 已输出 `funInsights`（含四维度计数）；`dashboard.service.spec.ts` 已测           |
| `DashboardService.getMyComparison` | 已输出 `myType` / `typePercentage` / `typeRank`                                  |
| `fun-insight-cards.tsx`            | 四卡 + 维度条初版；**无 Vitest**；无空数据态；维度条仅用 `primary`               |
| `personal-comparison.tsx`          | 登录且有结果时展示；`comparison === null` 时 `return null`（符合「未登录隐藏」） |
| `dashboard/page.tsx`               | 已挂载两组件；`authHint` 区分 guest / no_result                                  |

**结论**：T3.4 不是从零开发，而是对齐任务书验收的 **TDD + UI 打磨 + 边界态**，模式同 T3.2 / T3.3。

## 4. 组件设计

### 4.1 文件职责

| 文件                           | 职责                                                              |
| ------------------------------ | ----------------------------------------------------------------- |
| `fun-insight-cards.tsx`        | 四张趣味卡 + 维度平衡；导出可测纯函数                             |
| `fun-insight-cards.spec.tsx`   | Vitest：比例计算、空数据、渲染文案                                |
| `personal-comparison.tsx`      | 个人对比区；导出 `shouldShowPersonalComparison`（可选，便于单测） |
| `personal-comparison.spec.tsx` | Vitest：null 不渲染、有数据渲染字段                               |
| `dashboard/page.tsx`           | 仅当需要时调整 props（预计不改数据流）                            |

### 4.2 FunInsightCards 数据契约

沿用 `FunInsights`（`dashboard-api.ts`），不新增字段：

```typescript
mostCommonType: {
  (type, count, percentage);
}
rarestType: {
  (type, count, percentage);
}
mostPopularSprite: {
  (sprite, count);
}
dimensionBalance: {
  (E, I, S, N, T, F, J, P);
}
```

**展示规则**：

- 卡 1–3：`value` 为类型/精灵名；`detail` 为 `{count} 人（{percentage}%）`；`count === 0` 时 `detail` 为「暂无测评数据」。
- 卡 4「维度平衡」：四行 `E/I`、`S/N`、`T/F`、`J/P`；条宽 = `leftCount / (left+right)`，总数为 0 时各 50%。
- 区块标题保持「趣味数据」；`sm:grid-cols-2 lg:grid-cols-4` 响应式不变。

### 4.3 纯函数（导出供单测）

```typescript
/** 维度条左侧占比 0–100；总数为 0 时返回 50 */
export function computeDimensionBarPercent(left: number, right: number): number;

/** 是否应显示「暂无测评数据」副文案 */
export function formatInsightDetail(count: number, percentage: number): string;
```

### 4.4 PersonalComparison

**显示条件**（与验收一致）：

```typescript
// comparison 非 null 才渲染（fetchMyComparison 对游客返回 null，不发起或返回 null）
if (!comparison) return null;
```

**内容**（已有，微调文案）：

- 标题：「你的位置」
- 主文案：`你是 {myType} 类型`
- 副文案：`全体探索者中 {typePercentage}% 与你是同一类型`；`人数排名第 {typeRank} 位（共 16 型）`
- 视觉：与 Hero 渐变、`chart-3` 徽章圈对齐 T3.2 高亮色

**明确不做**：未登录时不显示占位骨架（避免与顶部虚线提示重复）。

### 4.5 页面布局（不变）

```
Hero → 登录提示（guest/no_result）→ 柱图|热力图 → FunInsightCards → PersonalComparison
```

个人对比仍在页面**底部**，趣味卡在上，符合 [2026-05-16-dashboard-design.md](./2026-05-16-dashboard-design.md) §3.2 线框图。

### 4.6 无障碍与深色模式

- 维度条容器 `role="img"` + `aria-label` 简述 E/I 比例（可选，至少保留可见数字）。
- 卡片边框 `border-[var(--border)]`、`bg-card` 与 T3.2 一致；深色模式依赖 CSS 变量，不硬编码浅色。
