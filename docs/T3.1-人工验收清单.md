## 一、后端 API 验收

### 1.1 `GET /dashboard/stats`（公开）

| #   | 操作                                           | 预期结果                                                                                                                               | 通过 |
| :-- | :--------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- | :--: |
| A-1 | `curl http://localhost:3001/dashboard/stats`   | 返回 200；`body.success === true`；`body.data` 含 `totalUsers`、`typeDistribution`、`spriteHeatmap`、`funInsights`                     |  ☐   |
| A-2 | 检查 `typeDistribution`                        | 数组长度 16；每项含 `type`、`count`；按 `count` 降序                                                                                   |  ☐   |
| A-3 | 执行 `pnpm db:seed:dashboard` 后再次请求 stats | `totalUsers > 0`（为 **TestResult 条数**，非去重用户数）；`spriteHeatmap` 非空；`funInsights.mostCommonType` / `rarestType` 有合理数值 |  ☐   |
| A-4 | 检查精灵映射                                   | `INFP` 等 I 开头类型对应 `月影探索精灵`；`ENFP` 等 E 开头类型对应 `曦光领航精灵`                                                       |  ☐   |
| A-5 | 空库场景（可选）                               | 无 `TestResult` 时仍 200；`typeDistribution` 16 项均为 0；`spriteHeatmap` 为 `[]`；不抛 500                                            |  ☐   |

| #   | 操作                                                         | 预期结果                                                           | 通过 |
| :-- | :----------------------------------------------------------- | :----------------------------------------------------------------- | :--: |
| B-1 | 无 `Authorization` 头请求                                    | 返回 401                                                           |  ☐   |
